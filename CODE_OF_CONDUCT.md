# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## Scope

This Code of Conduct applies within all community spaces - GitHub issues, pull requests, discussions, and any chat / email thread that involves the project - and also applies when an individual is officially representing the project in public spaces.

## Enforcement

Reports of abusive, harassing, or otherwise unacceptable behavior should be sent to:

- **bekaz@adwise.ge** with the subject line `[code-of-conduct] LobsterPay`

All complaints will be reviewed and investigated promptly and fairly. The maintainer is obligated to respect the privacy and security of the reporter of any incident.

## Enforcement guidelines

For the full guidelines and enforcement ladder, see the [Contributor Covenant 2.1 enforcement section](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
